# evaluation/metrics/

CSV files that reproduce the quantitative results reported in the paper.

## Files

| File | Reproduces | Source |
|------|-----------|--------|
| `aggregate.csv` | Table I — Convergence results per model and state | Paper Table I (post human review) |
| `per_layer_error_free.csv` | Table II — Correct SLOC rate (%) by CoSMA layer | Paper Table II |
| `per_package_sloc.csv` | Fig. 4 — Heatmap of SLOC error-free (%) per package | Paper Fig. 4 + pipeline reports |

## Authoritative values vs. pipeline reports

The values in `aggregate.csv` and `per_layer_error_free.csv` are the
**authoritative paper values**, obtained after human-in-the-loop review in
SysIDE/Eclipse IDE (§III.C). They correspond to the `.sysml` files in
`../models/case-study/{backbone}/final/`.

The `per_package_sloc.csv` file combines:
- SLOC counts from the automated pipeline reports (pre-human-review)
- Error-free percentages from Fig. 4 of the paper, which reflect the final
  state after human review for the 7 packages that exhibited non-100% rates

The SLOC figures in `aggregate.csv` are computed directly from the `.sysml`
files in `../models/case-study/{backbone}/final/` and can be independently
recounted with any line-counting tool, or regenerated by re-running the system.

## Note on warnings vs. errors

The paper's Table I reports **errors** only (syntax parsing failures).
The automated P5 validation reports produced by the pipeline report
`sloc_with_issues`, which combines errors and warnings. The CSV files use the
paper's error-only definition for consistency.
